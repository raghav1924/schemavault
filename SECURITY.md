## Reporting a Vulnerability

If you find a security vulnerability, SQL parsing bypass, or path traversal in SchemaVault, please notify us immediately by emailing **[raghavjatin245@gmail.com](mailto:raghavjatin245@gmail.com)**.

Please include:
1. Vulnerability description and steps to reproduce.
2. Sample SQL migration file triggering the issue.
3. Impact and severity assessment.
